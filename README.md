Portfolio Website

Overview

This portfolio website was developed as part of an examination project. The website showcases completed work processes, supporting evidence, project documentation, images, and PDF files in a structured and professional manner.

The project uses a consistent template system to present evidence and documentation across all work processes, making the portfolio easy to navigate and maintain.

Features
Responsive portfolio website structure
Navigation between all portfolio pages
Standardized project/evidence template
Support for:
Text documentation
Images
PDF attachments
Portfolio overview page with evidence buttons
Work process documentation for examination requirements
Consistent styling across all pages

Current Status

This repository contains the completed portfolio website and all implemented work processes.

Missing K2 Pages

The K2 pages are currently not included in this repository. Because of this, all navigation routes that point to K2-related pages will result in missing pages.

To fully restore the website:

Add the missing K2 HTML files to the project.
Open portfolio.html.
Locate the K2 navigation buttons and links.
Verify the referenced file names and routes.
Create or add the corresponding K2 HTML pages using the existing project template.

Once the K2 files have been added with the correct filenames and paths, all navigation routes will function as intended.

Template System

The project uses a reusable template page for portfolio evidence. Each evidence page follows the same structure:

Project description
Work process information
Images
Supporting PDF documents
Reflection and results

This ensures consistency throughout the portfolio.

Installation
Clone or download the repository.
Open the project folder.
Launch index.html in a web browser.

No additional dependencies or installation steps are required.
